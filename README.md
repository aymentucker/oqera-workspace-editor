# Oqera

Oqera is a bilingual (Arabic/English) intelligent developer workspace.

> Status: early foundation.

## Product principles

- Code first
- Fast by default
- Arabic + English from V1
- Native RTL/LTR interface support
- Code editor and terminal remain LTR by default
- Custom Oqera SVG icon system
- Desktop-first with macOS as the first development target

Active development happens on feature branches before merging into `main`.
