# Oqera V1

## Goal
A fast desktop code editor foundation that can become an intelligent developer workspace.

## V1 principles
- Code first
- macOS first; Windows next
- Arabic and English from day one
- UI supports RTL/LTR and automatic direction
- Code and terminal remain LTR by default
- Custom SVG icon language; no generic icon library
- Progressive complexity and keyboard-first workflows

## Milestones
1. Foundation
2. Workspace + files + Monaco
3. Search + Quick Open + Command Center + terminal
4. LSP code intelligence
5. Git
6. Product polish and packaging
